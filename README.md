"# Obsidian Project"
Vernacular \& Hinglish Search Failures: Regional users spell phonetically ("jharedi", "anarkli") or search with conversational terms, causing standard engines to return zero results or irrelevant items.   No Problem-to-Product Mapping: Users searching for everyday issues ("heel pain", "frizzy hair") get empty screens because catalogs only index product titles, not health or lifestyle problems.High Cart Abandonment from Empty Filters: Checking multiple filter attributes often leads to dead ends (zero items found), causing users to drop off.Flash Sale Crashes \& Overselling: Massive traffic spikes hit relational databases directly, causing deadlocks, slowdowns, and selling out-of-stock items.High Returns \& RTO Costs: Sizing ambiguity, low-trust unbranded listings, and high Cash on Delivery (COD) usage drive return rates up to 15–25%, destroying seller margins.   Low-End Mobile \& Network Lag: Heavy frontend bundles and poor image handling cause stutter and drop-offs on budget phones over 3G/4G networks.   Solutions ProposedPhonetic \& Voice Search Engine: Integrates Double Metaphone, fuzzy matching (Levenshtein $\\le 2$), and the Web Speech API to seamlessly parse Hinglish slang, typos, and spoken regional dialects.   Problem-to-Solution Knowledge Graph: Automatically translates problem queries ("back pain") into relevant functional categories ("lumbar support", "ergonomic chairs") via intent classification.Zero-Result Filter Suppression: Uses Roaring Bitmaps to calculate filter counts in real time ($<10\\text{ ms}$), automatically greying out unavailable combinations before users tap them.Atomic Flash Checkout (Redis + Lua): Deducts flash inventory in memory on a single thread to guarantee concurrency safety, backed by asynchronous queues (Kafka) to protect the main database.Smart Quick-Chips \& PWA Optimization: Surfaces one-tap budget filters ("Under ₹299", "Free Delivery") and uses a lightweight Next.js Progressive Web App (PWA) with list virtualization for 60fps scrolling on budget devices.   RTO Risk Scoring \& Fit Assistance: Predicts return risk at checkout, incentivizes instant UPI prepayments, and provides crowd-sourced sizing tags to reduce reverse logistics costs.
